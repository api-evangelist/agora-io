Agora released a new Agents SDK that simplifies voice agent development in Python, Node.js/TypeScript, and Go. The SDK provides typed pipeline builders and handles token generation and session management, letting developers configure agents with speech-to-text, language models, and text-to-speech components through clean, language-specific APIs rather than manual REST calls.
